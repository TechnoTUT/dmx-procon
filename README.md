# procon-light

Nintendo Switch の Pro Controller のようなゲームパッドで、照明を動かすツールです。右スティックを回すと色が変わり、ZR を押すとフラッシュします。

照明への出力は [dmxctl](https://github.com/TechnoTUT/dmxctl) が受け持ちます。このツールはコントローラーの操作を OSC にして dmxctl に送るだけなので、USB-DMX や Art-Net は今までどおり dmxctl につないだままで使えます。レーザーの安全の処理も、dmxctl の中をそのまま通ります。

## 使い方

1. dmxctl の設定で、OSC 受信を ON にします。ポートの既定は 9000 です
2. コントローラーをつなぎます。USB の有線でも、Bluetooth でもかまいません。Bluetooth は、Mac のシステム設定の Bluetooth でペアリングしておきます
3. このツールを起動します

```
cargo run --release
```

端末の1行に、今の色・明るさ・ムービングの向きと、最後にした操作が出ます。終わるときは Ctrl+C です。押していたフラッシュは戻してから終わります。

## 操作

| 操作 | 照明 |
|---|---|
| 右スティック | 色。倒す向きが色相で、上が赤、そこから時計まわりに黄・緑・水色・青・紫です。倒し具合が鮮やかさで、少しだけ倒すと淡い色になります。離してもその色のままです |
| 右スティック押し込み | 白 |
| 左スティック | ムービングの向き。倒した方へ動き、離すとそこで止まります |
| 左スティック押し込み | ムービングを正面に戻す |
| ZR | 押している間、白でフラッシュ |
| ZL | 押している間、今の色でフラッシュ |
| R | タップテンポ |
| L | 頭出し |
| A | メイン色とサブ色を入れ替え |
| B | 暗転フェード。押すたびに暗くする・戻す |
| X | ランダムな色 |
| Y | 色相を自動で回す。もう一度押すと止まる |
| 十字キーの上・下 | 全体の明るさを 10% ずつ |
| 十字キーの左・右 | LED バーのエフェクトを前・次へ |
| − | スティックの色をやめて、dmxctl のパレットの色に戻す |
| + | 一時停止。送るのを止める・再開する |
| キャプチャ | ジャイロで狙う。コントローラーを左右にひねる・前後に傾けると、ムービングがその向きへ動きます |

フラッシュ・タップ・ジャイロの切り替えなどでは、コントローラーが少し震えます。

起動しただけでは、色もムービングの向きも変えません。スティックを動かしたときから送ります。

## オプション

```
procon-light [--to HOST:PORT] [--movers 1,3,4] [--test]
```

- `--to`: dmxctl の OSC の送り先です。既定は `127.0.0.1` と、dmxctl の設定にある OSC のポートです。dmxctl が別のPCで動いているときに使います
- `--movers`: 左スティックで動かすムービングの番号です。番号は dmxctl のパッチタブの ID です。既定では、dmxctl の設定から、パン・チルトがあって ARM の要らない機材を選びます。レーザーは選びません
- `--test`: 何も送らずに、コントローラーの入力だけを見ます。ボタンの割り当てを確かめるときに使います

dmxctl の設定は `~/Library/Application Support/dmxctl/` から読みます。dmxctl と同じく、`DMXCTL_CONFIG_DIR` で場所を変えられます。

## ビルド

Rust と cmake が要ります。SDL2 はソースからビルドして実行ファイルに組み込むので、動かすPCに SDL2 を入れる必要はありません。

```
cargo build --release
```

コントローラーの読み取りには SDL2 を使っています。Pro Controller を、有線でも Bluetooth でも読めます。ジャイロと振動も SDL2 を通して使います。

## コードの地図

| ファイル | 中身 |
|---|---|
| `src/main.rs` | 起動、コントローラーの読み取り、端末への表示 |
| `src/control.rs` | 入力から送るものを決める。操作の割り当てはここ。テストあり |
| `src/osc.rs` | OSC を UDP で送る |
| `src/rig.rs` | dmxctl の設定から、ムービングと LED バーのエフェクトを探す |
